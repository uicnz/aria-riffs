# Markdown Rule Correlation Table

This table is based on direct, manual reading of both the Python rule implementation and the markdownlint rule documentation. Each row provides a side-by-side comparison of logic and behavior.

| ----------------------------------------- | ------------------------------------------------------- | ----------------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| ensure_h1_header                          | Inserts H1 at top if missing, using filename            | MD041             | Requires first line to be H1, HTML `<h1>`, or YAML frontmatter title    | Python rule auto-fixes, does not recognize HTML/YAML; markdownlint is more flexible, only lints       |
| ensure_blank_lines_around_headings        | Ensures exactly one blank line before/after headings    | MD022             | Requires at least one blank line before/after headings (configurable)   | Python rule is not configurable, always fixes to one; markdownlint can require more/fewer, only lints |
| demote_subsequent_h1_headings             | Demotes all but first H1 and their subheadings          | MD025             | Requires only one H1 (top-level heading)                                | Python rule demotes, markdownlint only reports; markdownlint recognizes YAML frontmatter              |
| fix_list_marker_spacing                   | Ensures 1 space after list markers, avoids HRs          | MD030             | Requires space after list markers (configurable)                        | Python rule not configurable, avoids HRs; markdownlint is configurable                                |
| remove_trailing_whitespace                | Removes trailing spaces from each line                  | MD009             | Reports trailing spaces, allows exceptions for hard breaks, code blocks | Python rule always removes, not configurable; markdownlint is configurable, ignores code blocks       |
| unindent_markdown_tables                  | Removes leading spaces from table lines                 | (No direct)       | -                                                                       | Custom rule, no markdownlint equivalent                                                               |
